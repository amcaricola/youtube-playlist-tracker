haremos una applicacion para guardar el registro de playlist de musica de youtube, la idea principal es guardar los datos (nuestros datos parceados pero extraidos del Api de youtube) titulo de cancion y nombre, y otros datos relevantes o interesantes, esto se hace con la finalidad de que, cuando un video se deshabilita o se elimina, youtube no informa que video, ni que contenido, ni el nombre del video eliminado, por lo que si una cancion es eliminada de la playlist, no hay manera de recuperar cual cancion era para poder reemplazarla, la idea es que la aplicacion lea la playlist mediante la Api-key, se conserve nuestros datos, mas algunos datos de youtube (los cuales se verificaran / actualizaran periodicamente en base a los ToS de youtube para no perjudicar al usuario que use la app) con esto queremos que si el video se pierde, el usuario pueda cambiar el item / video perdido por un video funcional para mantener la permanencia de la playlist
todo se trabajara con enfoque desde servidor, y con oAuth de youtube (ya que queremos que la app sirva como ), el servidor sera Hono Js y para la aplicacion usaremos preact y tailwind para css, los datos se guardaran en servidor con un JSON, no usaremos base de datos ya que eso añadira una capa de complejidad que no necesitamos
la app sera una SPA, debe solicitar antes que cualquier peticion de datos del servidor "la contraseña" del super usuario, una ves el usuario entre, el servidor le da un "token de acceso" de 30 dias, rebocable, el token debe almacenarce en localstorage, ten en cuenta que esta aplicacion solo tiene 1 super usuario, y las playlist son unicas de el, y entre las opciones deberia haber un "block all sesions" que reboca todos los tokens (el servidor debe almacenar estos tokens con su expiration date, para revocarlos o proibirles el acceso si es necesario) la pagina primero verifica la seguridad, y si el token es aceptado por el servidor, le permite acceder a la informacion mediante POST con el Token como "clave privada aceptada" por el servidor
en cuanto al funcionamiente de la app, luego de la verificacion, esta debe ingresar a la parte de la gestion, aca el usuario podra agregar la playlist que desea (mediante el link de la playlist) mediante la Api / oAuth (el servidor realizara la peticion a youtube, el cliente solo pide al servidor los datos) mostara la lista, y tras parsear los datos de la api y crear el JSON de la o las playlist agregadas por el usuario por la parte del cliente recibira el JSON y se colocara en modo lista (mostrando imagen, nombre de cancion, artista, y otros... lo vemos despues) lo ideal es que al parsear, ahora sea "nuestra lista de datos", y no los datos de youtube para evitar violacion de ToS, si hay datos adicionales que sea necesarios de la Api, el servidor se debe encargar de "refrescarlos" cada 24 horas o una vez al dia (esto puede ser un campo adicional del JSON para confirmar que esta "revisado" esa cancion ese dia) esto tambien se debe hacer en lotes pequeños poco a poco para no saturar la API / solicitudes oAuth
lo ideal es que la app verifique el estado de los items en la playlist, si esta activo o si se daño / deshabilito el link, si se deshabilito gracias al oAuth (tengo entendido que se puede hacer) permitir al usuario "eliminar la cancion vieja o cambiar la cancion dañada" si esta deshabilitado temporalmente (es decir asumiendo que en unas horas o dias lo recuperara, podriamos analizarlo cuando se toque este punto) lo ideal seria que el usuario pueda modificar su propia playlist desde la app, ademas, al darle al boton de "recuperar cancion dañada" se deberia hacer una busqueda a youtube y ofrecer desde nuestra app, la modificacion / recuperacion del item dañado, como nuestros datos "artista y cancion" se mantienen, podemos reemplazarla por una nueva cancion activa, y mediante el boton ofrecerle opciones que el usuario clickee y la api / oAuth haga el cambio internamente de la playlist
ademas de eso, como tema de mejora de funcionalidad, cada item (en hover) debe tener un boton de "reprocir" que envie a en youtube para reproducir la cancion si el usuario lo desea, ademas de eso, la playlist debe tener un filtro de busqueda por cancion o artista, ademas debe haber un segundo filtro de artista que permita seleccionar un "artista de la lista" (mediante un deplegable) y al seleccionar, lo filtra (de esta manera el usuario puede "analizar" o ver completamente las canciones que tiene de ese artista)
